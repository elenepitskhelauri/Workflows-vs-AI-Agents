# Workflows vs AI Agents — NEXLEVR Quest 3

A short design document plus a runnable Python demonstration of three business automation patterns.

## Run on Windows

1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run `python demo.py`.

Uses only the Python standard library; no `pip install` required. The demo uses simulated employee and customer requests and illustrative URLs; it does not connect to live systems.

See [DESIGN.md](DESIGN.md) for the business comparison and recommendations.
